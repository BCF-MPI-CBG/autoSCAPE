# autoSCAPE

`autoscape` is a [napari] plugin to read, write, and process data acquired with a SCAPE (Swept Confocally-Aligned Planar Excitation) microscope, speeding up high-throughput acquisitions such as multiwell-plate screens.

It provides napari widgets for acquisition planning (tile grids, well grids, focus-plane fitting) and stage-position export, together with library functions for converting vendor tile/stage data into OME-Zarr and for automatically detecting regions and focus planes with trained deep-learning models.

## Installation

Install `autoscape` with [pip]:

```bash
pip install autoscape
```

To use the optional YOLO/focus-detection models, install the `dl` extra:

```bash
pip install "autoscape[dl]"
```
